How to use this map

Navigate. Scroll or pinch to zoom, drag to pan. Zoomed out you see the main areas. Zoom in to see topics, then individual questions and projects. Click a node for details. Double-click a node to fly to it. Drag a node to move it, and its children move with it. The address bar link points at the selected node, so you can share it. Keys: / search, f fit, Esc close.

Edit. In the side panel: Edit, + Child, + Link. Lists such as questions and experiments take one item per line.

Saving. If you run python3 serve.py and open http://127.0.0.1:8765/map.html, edits are written straight to data.js, with backups in backups/. If you open map.html as a file, edits stay in this browser until you click Export and replace data.js with the download.

Ask Claude. Copy prompt for Claude copies this node's context and asks Claude to fill in the area: literature, bottlenecks, open questions, and new nodes and links. Claude edits data.js directly. Reload the page to see the changes.

Literature entries are starting points written from memory. Check them before citing.
